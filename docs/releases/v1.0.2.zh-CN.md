# Quanterdeck v1.0.2 — 2026-10-11

[English](v1.0.2.md) · [简体中文](v1.0.2.zh-CN.md)

- **盈亏卡突出显示带正负号的金额。** 主金额使用大字，下方／旁边以小字显示占当前
  权益的比例，记账明细也改为小字。净盈亏未测得时，明确显示“已实现盈亏”；盈利
  绿色、亏损红色、零值中性。当前权益缺失或非正时不显示百分比。
  （[#76](https://github.com/openquanter/quanterdeck/pull/76)）
- **绿色新版提示直接进入升级页面。** 点击分别进入控制台或框架区域，侧栏「系统」
  下也提供固定入口。控制台区域包含发布包下载、校验命令和服务替换步骤；框架区域
  连接签名交易构件部署。（[#75](https://github.com/openquanter/quanterdeck/pull/75)）
- **发布说明提供完整的按版本中文翻译入口**，并关联各项改动的来源 PR。
  框架依赖继续固定在 OpenQuanter `v2.0.1`。
  （[#77](https://github.com/openquanter/quanterdeck/pull/77)）
