# 安全模型

> 本文写明这个控制台防什么、怎么防、以及**不防**什么。
> 有安全问题请私下报告，不要开公开 issue。

## 前提

Quanterdeck 是单操作者、自托管的控制台。它读交易系统的运行结果，并且在开启写入
后**能下单**。它默认监听 `127.0.0.1`。

## "只听回环所以不用登录"是错的

这个项目一度这么设计过。它错在四处，每一处都很平常：

1. **回环不是用户边界。** 同一台机器上的任何进程、任何其他账号都能连上回环端口。
   交易主机上这两者都不止一个。
2. **操作者的浏览器可以被诱导访问它。** DNS rebinding 把攻击者控制的域名解析到
   `127.0.0.1`，此后操作者打开的任何页面都能以同源身份和这个控制台对话。
   套接字分辨不出来，`Host` 头可以。
3. **第一次端口转发之后绑定就不成立了。** 人一定会用 `ssh -L`，之后"回环"只
   描述服务端的套接字，不描述连接的另一头是谁。
4. **开了写入它就能动钱。** 一个不需要认证、又能下单的服务，不会因为它在哪里
   监听而变安全。

所以**认证是无条件的**。绑定回环只换来一件事：第二因素变成可选。

## 防的是什么

| 威胁 | 措施 |
|---|---|
| 同机其他进程或用户打开端口 | 会话 cookie，始终必需 |
| DNS rebinding 让浏览器页面访问 `127.0.0.1` | `Host` 白名单，最外层执行 |
| 该页面读取响应或借用会话 | `SameSite=Strict` + 写入时的 `Origin` 校验 |
| 从日志里读到令牌或 cookie | 两者都永不写日志 |
| 猜密码 | Argon2id + 5 次失败锁定 15 分钟 |
| 被窃取的 cookie 长期有效 | 空闲 1 小时、绝对 12 小时，服务端强制 |
| 路径穿越读到目录外的文件 | id 只在目录列表里匹配，永不路径拼接 |
| 账户信息进入日志/history/referrer | 对账记录走 POST body，不走 query string |

检查顺序是固定的，最外层是 `Host`：一个过不了 `Host` 检查的请求根本走不到会话
查找，因此攻击者无法在那里用时间差判断会话是否存在。

## 具体做法

- **密码**：Argon2id，19 MiB / 2 pass / 并行度 1（OWASP 低内存档）。选低内存档
  是刻意的——控制台与被监视的交易进程同机，一次登录不该抢走它需要的内存。
- **首次引导**：没有密码时，deck 在**启动它的那个终端**打印一次性令牌。读到它
  需要操作者本就拥有的本机访问权限；令牌只在进程内存中，永不落盘、永不进日志。
- **会话**：256 位 CSPRNG 令牌；`HttpOnly`、`SameSite=Strict`、`Path=/`；
  只有在 `OQ_DECK_BEHIND_TLS=1` 时才加 `Secure`（否则浏览器会在
  `http://localhost` 上静默丢弃它，操作者会对着一个没反应的登录页发呆）。
  会话存在内存里：重启即登出。对一个监视交易进程的控制台，这个取舍是对的——
  另一种做法是把一个比签发理由活得更久的令牌写到磁盘上。
- **TOTP**：RFC 6238，±1 步（90 秒）窗口。回环上可选，非回环上必需。
  窗口不放宽：每多一步，就多一个"被人从背后看到的验证码仍然有效"的窗口。
- **常数时间比较**：令牌与验证码用 `subtle::ConstantTimeEq`。
- **失败不透露信息**：登录失败只说"密码或验证码不正确"，不区分是哪一个错。
  存储的 hash 损坏与密码错误在内部是不同的错误类型——把前者当后者报，会让人
  去重置一个本来没问题的密码。

## 不防什么

- **不防拿到本机 shell 的人。** 能读启动终端、能读环境变量的人就是操作者。
- **不做多用户、不做权限分级。** 这是单操作者工具。
- **不代管交易所密钥。** 对账所需的账户快照由操作者**粘贴**进来。控制台没有
  交易所凭证，将来也不会有——这是上游明确的非目标，这里也一样。
- **不自带 TLS。** 要在网络上暴露，请放在一个终止 TLS 的反向代理后面，并设置
  `OQ_DECK_BEHIND_TLS=1` 与 `OQ_DECK_EXTRA_HOSTS`。

## 尚未做的（记在这里而不是假装没有）

- **危险操作的二次认证（step-up）**：目前开启写入后，会话内的写入不再要求重新
  输入密码。下单类操作应当要求。
- **审计日志**：谁在什么时候做了什么，尚未持久化。
- **配置文件**：`setup` 目前把 hash 与 TOTP secret 返回给操作者，由操作者放进
  环境变量。有配置文件后应由 deck 自己写入并设好文件权限。
